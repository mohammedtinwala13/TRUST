active module / honesty layer

Useful. Not magic.

A web page can estimate browser risk. It cannot see inside the operating system. That boundary is part of the product, not a footnote.

01
Kernel keyloggers

OS-level hooks, hardware skimmers, and malicious USB devices are outside browser sandbox access.

02
Shoulder surfing

No web app can tell whether someone is watching the screen. Check your surroundings.

03
False positives

Low-end hardware or browser privacy tools can look unusual. Treat warnings as prompts to verify.

04
High-risk verdict

If a critical browser signal fails, do not enter credentials. Move to a trusted device.
